# NixOS configuration (`~/.dotfiles`)

Modular NixOS + Home Manager configuration, migrated and reorganized from `~/Nixos-config`.

- **Location:** `~/.dotfiles`
- **Flake outputs:** `nixosConfigurations.<host>` (one per directory in `hosts/`), `formatter.x86_64-linux`, `checks.x86_64-linux.lint`, `devShells.x86_64-linux.default`
- **Host:** `infinix` — hostname `nixos-btw`, user `mordred`, timezone `Asia/Kolkata`, `stateVersion` `26.05`
- **Composed from:** a flake (`flake.nix`) → any number of hosts → the shared `modules/system` bundle plus opt-in `modules/features`, `modules/system/packages/apps.nix` and `modules/home/apps`; Home Manager (`modules/home`) is embedded in the NixOS config, so a single rebuild switches the system *and* the user environment.
- **Opt in / opt out:** every optional module is gated by a `dotfiles.*` switch declared in `modules/options.nix` and set by the host. Nothing optional is enabled by default, so a new host starts minimal and stays headless until it asks for a desktop.
- **Guide:** [`HOSTING.md`](HOSTING.md) — file structure, `nh` commands, adding/changing a host, and the opt in/opt out switches.

## 2. What each file does

### Flake level

| File | Purpose |
| --- | --- |
| `flake.nix` | Declares inputs (nixpkgs-unstable, home-manager, treefmt-nix, umbriel, noctalia, noctalia-greeter, helium, millennium, sonora, bonfire), a `nixosConfigurations.<host>` for every directory in `hosts/`, the treefmt-based `formatter`, a `checks.lint` derivation, and a dev shell with deadnix/nixfmt/statix. Each host also gets `modules/options.nix` and `inputs` as special args. |
| `flake.lock` | Exact input revisions. Regenerated automatically whenever inputs change. |
| `statix.toml` | Excludes generated `hosts/*/hardware-configuration.nix` from linting. |

### `modules/options.nix` — the opt-in switches

Every optional module reads one of these. A host turns a module on or off in
its own `default.nix`; the default is always `false`, so a host only gets what
it asks for.

| Switch | Gates |
| --- | --- |
| `dotfiles.desktop.enable` | `modules/system/desktop.nix` (Umbriel, greeter, pipewire, libinput, dconf, xwayland) and every `modules/home/desktop` module |
| `dotfiles.features.browser.enable` | `modules/features/browser.nix` |
| `dotfiles.features.gaming.enable` | `modules/features/gaming.nix` |
| `dotfiles.features.jupyter.enable` | `modules/features/jupyter.nix` |
| `dotfiles.features.python.enable` | `modules/features/python.nix` |
| `dotfiles.features.virtualization.enable` | `modules/features/virtualization.nix` |
| `dotfiles.apps.bonfire.enable` | `modules/home/apps/bonfire.nix` |
| `dotfiles.apps.fastfetch.enable` | `modules/home/apps/fastfetch.nix` |
| `dotfiles.apps.krita.enable` | `modules/system/packages/apps.nix` |
| `dotfiles.apps.libreoffice.enable` | `modules/system/packages/apps.nix` |
| `dotfiles.apps.mime.enable` | `modules/home/apps/mime.nix` |
| `dotfiles.apps.nautilus.enable` | `modules/home/apps/nautilus.nix` |
| `dotfiles.apps.obsidian.enable` | `modules/system/packages/apps.nix` |
| `dotfiles.apps.sonora.enable` | `modules/home/apps/sonora.nix` |
| `dotfiles.apps.spotify.enable` | `modules/system/packages/apps.nix` |
| `dotfiles.apps.vesktop.enable` | `modules/system/packages/apps.nix` |
| `dotfiles.apps.vscode.enable` | `modules/home/apps/vscode.nix` |
| `dotfiles.apps.whatsapp-electron.enable` | `modules/system/packages/apps.nix` |

NixOS modules read them from `config.dotfiles.…`; Home Manager modules read
them from `osConfig.dotfiles.…`, which is how a NixOS option reaches the
embedded Home Manager evaluation. Gated modules use `lib.mkIf`, and because
`imports` is not a normal option it can never live inside a conditional module
— that is why the greeter module is imported unconditionally
and only their settings are gated.

### Host layer (`hosts/infinix`)

| File | Purpose |
| --- | --- |
| `default.nix` | Host entry point. Sets `_module.args.userName`, hostname, timezone, the `dotfiles.*` opt-ins, and imports `./audio`, `./hardware-configuration.nix`, `modules/system`, `modules/features`. Add host-only settings here. |
| `hardware-configuration.nix` | Generated file describing disks/GPUs/filesystems. Do not hand-edit. |
| `audio/default.nix` | Machine-specific audio: builds the patched out-of-tree `snd-soc-sof_es8336` module (quirks now come from DMI), points PipeWire/WirePlumber at the patched UCM2 tree via `ALSA_CONFIG_UCM2`, and installs `sof-firmware`/`alsa-ucm-conf`/`alsa-utils`. |
| `audio/es8336-fix.nix` | `stdenv.mkDerivation` that compiles `./patch` against `config.boot.kernelPackages` and installs `snd-soc-sof_es8336.ko` into the kernel's `extra/` directory. |
| `audio/ucm.nix` | Overlays the ES8326 profile from android-generic's `alsa-ucm-conf` fork onto the stock `alsa-ucm-conf` tree, so the internal microphone is exposed instead of being skipped when ES8316-only controls are missing. |
| `audio/patch/*` | The driver patch itself (`sof_es8336.c` adds a non-inverted headphone GPIO quirk, DMI entries for the Infinix models and an HDMI FE PCM count override), its headers, and a kbuild `Makefile`. |

#### Audio (INBOOK X2 SLIM)

The card is an Intel SOF `sof-essx8336` machine driver with an ES8326 codec,
which the stock kernel and UCM profiles only half-support. Two things are
wrong out of the box:

- After kernel 6.18.9 the machine driver drives the headphone GPIO inverted,
  which leaves the speaker silent.
- The `sof-essx8336` UCM profile is written for the ES8316/ES8336 and sets
  controls the ES8326 does not have (`Differential Mux`, `Digital Mic Mux`).
  alsa-lib aborts the whole `EnableSequence` on a failed `cset`, so the
  internal microphone section never initialises.

Both are handled in `hosts/infinix/audio`:

- `patch/sof_es8336.c` is the out-of-tree driver with the non-inverted GPIO
  quirk, DMI entries for the Infinix laptops, the pop/trigger rework and an
  HDMI FE PCM count parameter. The quirk now comes from DMI
  (`quirk mask 0x200`), so there is **no** `quirk=` modprobe option — an
  override would turn the inversion back on and kill the speaker.
- `ucm.nix` overlays the ES8326 profile from android-generic's
  `alsa-ucm-conf` fork onto the stock tree, and `default.nix` exports
  `ALSA_CONFIG_UCM2` to PipeWire, WirePlumber and PipeWire-Pulse so they load
  it.

Result: the speaker survives reboots and mute/unmute, and the internal
microphone shows up as a normal PipeWire source instead of the "unplugged"
headset mic plus a virtual-mic workaround. Verify with:

```bash
journalctl -k -b | grep essx8336   # expect quirk mask 0x200 + "headphone GPIO non-inverted"
wpctl status                       # expect "Internal Microphone" under Sources
```

### Bonfire new tab

With `dotfiles.apps.bonfire.enable`, the rebuild installs the `bonfire` flake
input and starts a darkhttpd user service serving the page from
`~/.local/share/bonfire` on `http://127.0.0.1:8420/`. Its `bonfire.css` template
is registered under `programs.noctalia.settings.theme.templates.user.bonfire`,
so each wallpaper change re-renders the palette into `colors.css` (already-open
tabs pick it up within ~500 ms).

Point a new-tab override extension — [New Tab
Override](https://addons.mozilla.org/en-US/firefox/addon/new-tab-override/) with
*Custom URL* — at `http://127.0.0.1:8420/`, and enable *Set focus to the web
page instead of the address bar*. The service is `systemctl --user status
bonfire`; its port lives in `modules/home/apps/bonfire.nix`.

## 4. Commands

### Daily use

```bash
# Apply system + user configuration (Home Manager included)
sudo nixos-rebuild switch --flake ~/.dotfiles#infinix

# Same thing through nh, with progress output
sudo nh os switch ~/.dotfiles#infinix

# Test a rebuild without touching the running system (boots into the new generation on next reboot)
sudo nixos-rebuild test --flake ~/.dotfiles#infinix

# Build the new system without activating it
sudo nixos-rebuild build --flake ~/.dotfiles#infinix

# Pick which generation to boot (after `test` or a failed boot)
sudo nixos-rebuild rollback
sudo nixos-rebuild rollback 2      # two generations back
sudo grub-reboot                  # one-shot boot of the previous generation

# Only the user environment (equivalent to the HM half of a rebuild)
home-manager switch --flake ~/.dotfiles#infinix
```

`nh os` wraps the same operations (`switch`, `boot`, `test`, `build`, `repl`,
`rollback`, `build-vm`), `nh search` looks options up on search.nixos.org, and
`nh clean` is a GC helper. It needs the attribute path unless the hostname
matches the host directory name, which is why the commands above say
`#infinix` (`networking.hostName` is `nixos-btw`).

### Adding a host

```bash
mkdir -p ~/.dotfiles/hosts/<name>

cat > ~/.dotfiles/hosts/<name>/default.nix <<'EOF'
{
  _module.args.userName = "<user>";

  imports = [
    ./hardware-configuration.nix   # from nixos-generate-config

    ../../modules/system
    ../../modules/features
  ];

  dotfiles = {
    desktop.enable = true;         # omit for a headless host
    # features.* / apps.* as needed; everything is off by default
  };

  networking.hostName = "<name>";
}
EOF

# The flake picks the directory up automatically
nix flake check
sudo nixos-rebuild switch --flake ~/.dotfiles#<name>
```

### Validate before rebuilding

```bash
cd ~/.dotfiles

nix flake check                    # evaluate system + formatting + lints
nix flake check --no-build         # evaluate only, skip buildable checks

# Build the generated Umbriel config and validate it (runs `umbriel config
# validate`, which also checks every keybind chord, action name and enum)
UMBRIEL_CFG=$(nix build --no-link --print-out-paths \
  ".#nixosConfigurations.infinix.config.home-manager.users.mordred.xdg.configFile.\"umbriel/config.toml\".source")
UMBRIEL_BIN=$(nix build --no-link --print-out-paths \
  ".#nixosConfigurations.infinix.config.programs.umbriel.package")/bin/umbriel
"$UMBRIEL_BIN" config validate -c "$UMBRIEL_CFG"   # -> config: ok

# Inspect a value before switching
nix eval .#nixosConfigurations.infinix.config.networking.hostName
nix eval .#nixosConfigurations                       # every host the flake knows about
nix eval .#nixosConfigurations.infinix.config.dotfiles.features.gaming.enable
nix eval --json .#nixosConfigurations.infinix.config.home-manager.users.mordred.programs.umbriel.settings.keybinds \
  --apply 'b: builtins.length (builtins.attrNames b)'    # number of keybinds
```

### Formatting and linting

```bash
cd ~/.dotfiles

nix fmt                            # treefmt -> nixfmt on every *.nix file
nix develop                        # shell with deadnix, nixfmt, statix

statix check .                     # lint
nixfmt --check $(find . -name '*.nix')

# unused arguments/bindings; deadnix only takes literal excludes, so the
# generated hardware-configuration.nix of every host is filtered by name
# (this is what checks.lint runs)
find . -name '*.nix' ! -name 'hardware-configuration.nix' -print0 \
  | xargs -0 deadnix --fail
```

### Updating inputs

```bash
cd ~/.dotfiles

nix flake update                              # everything
nix flake update umbriel noctalia            # selected inputs
nix flake lock                                # just re-lock (no version bumps)
nix flake check                               # verify afterwards
sudo nixos-rebuild switch --flake ~/.dotfiles#infinix
```
